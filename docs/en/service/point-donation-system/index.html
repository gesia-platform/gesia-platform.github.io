Point Donation System

In order to use third-party member points for carbon offset purposes (either retirement or donation), it is necessary first to exchange these points into the points of the carbon offset app. This exchange process is verified and validated through blockchain technology, providing transparent information to the third-party members.

G-Point offset points are intended to be used in token form, allowing users to purchase vouchers and derivative tokens. Subsequently, if users engage in carbon offset activities such as retirement or donation using these tokens, they will be rewarded with NZC tokens.
