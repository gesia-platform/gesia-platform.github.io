토큰

시드 토큰 (SEED Token)

시드 토큰은 탄소 배출 및 상쇄 데이터를 수집, 분석, 집계하기 위해 디지털화된 기본 단위 토큰 입니다.

토큰의 형태 : ERC1155

  • ERC1155는 하나의 스마트 컨트랙트에서 대체 가능 토큰과 대체 불가능 토큰을 동시에 관리할 수 있는 유연성을 제공하며, 이는 단위 형태의 토큰 관리에 최적화되어 있다.

바우처 토큰 ( Voucher Token )

바우처 토큰은 외부 데이터를 체인에서 토큰으로 발행한 데이터 토큰이다. 이를 체인에 배포하기 위해서는 공증 오라클(Notary Oracle)이 필요하며, 공증 오라클은 외부 데이터를 제공하는 계정과 수신하는 계정 간의 다중 서명을 통해 데이터의 신뢰성을 증명한다.

토큰의 형태 : ERC1155

  • ERC1155는 하나의 스마트 컨트랙트에서 대체 가능 토큰과 대체 불가능 토큰을 동시에 관리할 수 있는 유연성을 제공하며, 이는 레지스트리 형태의 토큰 관리에 최적화되어 있다.

확장된 토큰 ( Extended Token )

확장된 토큰은 바우처 토큰을 수탁하여 새롭게 발행된 토큰으로, 외부 데이터로 서명된 바우처 토큰에서 확장되었음을 증명한다. 이 토큰은 바우처 토큰을 새로운 용도로 활용하기 위해 배포되었으며, 특히 더블 카운팅(Double Counting) 문제를 방지하여 외부 데이터의 신뢰성과 무결성을 증명한다.

토큰의 형태 : ERC1155

  • ERC1155는 하나의 스마트 컨트랙트에서 대체 가능 토큰과 대체 불가능 토큰을 동시에 관리할 수 있는 유연성을 제공하며, 이는 다중 토큰 관리와 배치 전송(batch transfer) 기능을 통해 다수의 파생 토큰을 관리에 최적화되어 있다.
