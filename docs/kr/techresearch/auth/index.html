인증

탄소 인증

탄소 인증은 탄소 배출, 상쇄, 거래 데이터 제공자와 평가자를 신뢰할 수 있도록 검증하고, 공증 계정 권한을 부여하는 절차이다.

배출 인증

배출 인증은 배출 데이터를 제공하는 주체와 감축 데이터를 평가하는 주체를 인증하는 절차이다.

데이터 제공자 인증

  • 배출 데이터를 제공하는 주체의 신원을 확인하고 검증한다.

  • 검증된 제공자에게 배출 데이터를 제출할 수 있는 권한을 부여한다.

배출 데이터 감축 평가자 인증

  • 제출된 배출 데이터를 평가할 평가자의 신원을 확인하고 검증한다.

  • 평가자는 제공된 데이터의 정확성과 감축 효과를 객관적으로 검토하고 승인한다.

상쇄 인증

상쇄 인증은 상쇄 데이터를 제공하는 주체와 상쇄 데이터를 평가하는 주체를 인증하는 절차이다.

데이터 제공자 인증

  • 상쇄 데이터를 제공하는 주체의 신원을 확인하고 검증한다.

  • 검증된 제공자에게 상쇄 데이터를 제출할 수 있는 권한을 부여한다.

상쇄 데이터 평가자 인증

  • 제출된 상쇄 데이터를 평가할 평가자의 신원을 확인하고 검증한다.

  • 평가자는 제공된 데이터의 정확성과 탄소 흡수량을 객관적으로 검토하고 승인한다.

거래 인증

거래 인증은 탄소 크레딧 토큰 ( 확장 토큰 ) 을 발행하거나 거래하는 주체를 인증하는 절차이다.

발행자 인증

  • 탄소 크레딧 토큰의 발행 및 배포 주체의 신원을 확인하고 검증한다.

  • 검증된 발행자에게 탄소 크레딧 토큰의 발행 및 배포 권한을 부여한다.

거래자 인증

  • 탄소 크레딧 토큰을 거래하는 주체의 신원을 확인하고 검증한다.

  • 검증된 거래자에게 탄소 크레딧 토큰을 거래할 권한을 부여한다.
